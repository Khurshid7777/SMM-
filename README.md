# Silicare Reels

Кастомизированный плагин Remotion для SMM силиконовых пластырей **sil·icare by Yafho**: бренд-стиль, автопроверка медицинской рекламы, 7 сценариев Reels на RU и UZ и сборка роликов 1080×1920, 24 fps.

## Что внутри

| Путь | Что это |
|---|---|
| `plugins/silicare-reels/` | Плагин Claude Code: 4 скила — стиль, автопроверка, сборка роликов, идеи (28 тем + факты с источниками) |
| `.claude-plugin/marketplace.json` | Маркетплейс для установки плагина из этого репозитория |
| `content/reels/*.json` | 7 сценариев из плана: покадрово, титры RU/UZ, подписи, хэштеги, утверждения с источниками |
| `content/brand.json` | Палитра, шрифт, safe zones, черновик дисклеймера RU/UZ |
| `content/product.json` | Продукт по брошюре Yafho: вид, размеры, применение, расхождения со стратегией |
| `content/forbidden.json` | Запрещённые фразы, валюты, запреты в кадре |
| `content/glossary.json` | Термины RU→UZ для носителя языка |
| `content/schema.json` | Схема файла ролика |
| `scripts/check.mjs` | Автопроверка: любая ошибка останавливает публикацию |
| `schedule.csv` | Расписание, статус «утверждено» ставит владелец |
| `video/` | Remotion-проект: композиции `<id>-ru` и `<id>-uz` для каждого ролика |

## Быстрый старт

```bash
node scripts/check.mjs          # автопроверка всех сценариев
cd video && npm i
npm run dev                     # Remotion Studio: превью всех роликов
npm run render:all              # проверка + рендер всех роликов в video/out (3D: --gl=swangle по умолчанию)
```

Установить плагин в Claude Code:

```
/plugin marketplace add Khurshid7777/SMM-
/plugin install silicare-reels@silicare
```

## Как это работает

1. Сценарий живёт в JSON. Пока съёмки нет, в каждом кадре — **3D-сцена продукта** (`shot.scene`, three.js): прозрачный силикон с преломлением и бликами, плёнка с сеткой, упаковка, рука с фактурой кожи, реквизит — в предметной студии в духе Hims & Hers (пастельная циклорама, софтбокс, контактная тень). Вид продукта — по брошюре Yafho. Упаковка — макет до фото реальной коробки.
2. После съёмочного дня клипы кладутся в `video/public/footage/<id>/shot-<n>.mp4`, а у кадра прописывается `"clip"`. Шаблон обрежет под 9:16, добавит медленный наезд и тёплую коррекцию.
3. Заголовок слева крупным геометрическим шрифтом, до 7 слов, слова появляются по очереди; под ним — пилюли-преимущества. Верх 250 px и низ 300 px свободны.
4. Финал — знак `sil·icare by Yafho · @sil.icare`, кнопка-действие и дисклеймер медизделия (если продукт в кадре).
5. Ролик 4 «Почему рубец становится грубым» — анимация среза кожи кодом, без съёмки и без красного.

## Перед первой публикацией (из плана)

- Ответ юриста: графика UZ, формулировка дисклеймера и удостоверения, пометка «Реклама».
- Инструкция Yafho: заменить все источники «— УТОЧНИТЬ» на разделы инструкции (сейчас 15 предупреждений).
- Проверка UZ-текстов носителем → `reviewed_by_native_uz: true`.
- Логотип из бренд-кита заменит текстовый знак в `video/src/Reel.tsx`.

## Шрифт

Титры набраны **Montserrat** (SIL OFL, `video/public/fonts`) — геометрический гротеск, ближайший бесплатный аналог Sofia Pro из стиля Hims & Hers, с узбекскими **ў қ ғ ҳ**. В Manrope из брендбука нет қ ғ ҳ. Если бренд-кит предложит другой шрифт — сначала проверьте в нём эти буквы.
