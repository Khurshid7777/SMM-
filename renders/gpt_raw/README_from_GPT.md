# Silicare — подготовленные GPT-кадры

Пакет от 26.10.2026. Частичная передача по ТЗ-1 и ТЗ-2, не полный комплект.

## Внутри
- R1_bg.png — фон для R1 и R5, без товара и надписей.
- R4_bg.png — фон для таймлайна R4.
- END_bg.png — фон финальной карточки; декоративная волна является частью фона.
- R2_skin_forearm.png — иллюстративный слой предплечья с зажившим линейным рубцом, без ленты. PNG содержит альфа-канал. Это не фотография пациента и не доказательство результата лечения.

Фоны: 941×1672, приблизительно 9:16. Слой предплечья: 1024×1536. Это исходное разрешение генерации, не финальный мастер 1080×1920. Перед экспортом учитывать масштабирование; реального запаса 20% сверх кадра 1080×1920 нет. Для сильных наездов нужна генерация большего размера. Цвета визуально близки к ТЗ, точное совпадение HEX для растров не гарантируется. Первые фоны созданы по ТЗ-2 до получения ТЗ-1.

## Передача в Claude Code
Скопировать содержимое renders/gpt_raw/ в одноимённую папку проекта silicare/. Имена совпадают с ТЗ-2. Текст и логотип добавлять отдельными слоями из утверждённых brand/ и data/. Сохранить альфа-канал предплечья. На END_bg волна уже нарисована: для независимой анимации волны нужен отдельный слой. Не использовать R2_skin_forearm как кадр «до» с обещанием улучшения.

## Что ещё требуется для завершения GPT-части
1. Утверждённые box_front PNG/плоский дизайн коробки для четырёх SKU и выбранный логотип.
2. Фото настоящего рулона, фактуры и защитной плёнки. Замеры рулонов и коробок.
3. После этого: закрытая/открытая коробка в одном ракурсе, рулон отдельным слоем, нанесённая лента на этом же предплечье, руки с ножницами, четыре коробки отдельными PNG; затем P1–P10 из ТЗ-1.

Без этих референсов точные товарные изображения получить нельзя. Пустые файлы вместо недостающих изображений в пакет не включены. Медицинские тексты и видео в этом пакете не создавались и не проверялись.
